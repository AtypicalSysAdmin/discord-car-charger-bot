## 1. Architecture Map & Folder Breakdown

Dual-service single-process system: a Discord Bot (`discord.py`) and a Web Dashboard (`Flask`) orchestrated by `app.py`.

```
discord car charger bot/
├── app.py              # System entry point: initializes state, starts Flask daemon thread, blocks on bot.run()
├── bot.py              # ChargerBot subclass: slash commands, 30s background reminder loop, DM cleanup
├── dashboard.py        # Flask app (port 5000): REST API endpoints (/api/status, /api/action/*) and static UI
├── state.py            # SharedState: thread-safe persistent state machine and Pacific timezone shift scheduler
├── templates/
│   └── index.html      # Glassmorphic dark UI dashboard with real-time fetch & visual timers
├── deploy.ps1          # Deployment wrapper delegating to CentralDeployTools for remote Linux deployment
├── requirements.txt    # Production dependencies: python-dotenv, discord.py, flask, pytz
├── bot_state.db        # Production SQLite state store (CRITICAL: live data)
└── graphify-out/       # Knowledge graph artifacts generated by graphify
```

### Threading & Concurrency Topology
- **Main Thread**: Runs `ChargerBot.run(TOKEN)` (asyncio event loop).
- **Background Daemon Thread**: Runs Flask dashboard via `threading.Thread(target=run_dashboard, args=(bot,), daemon=True)`.
- **Cross-Thread Bridge**: Flask actions communicate with Discord's event loop via `asyncio.run_coroutine_threadsafe(coro, bot_ptr.loop)`.
- **State Synchronization**: `SharedState` (`state.py`) acts as the single source of truth for both threads, synchronizing mutations immediately to SQLite.

## 3. Inviolable Constraints & Operational Gotchas

- **Timezone Rules (US/Pacific)**:
  - All shift boundary calculations (`calculate_shift_and_target`) and mute calculations strictly operate in `US/Pacific` (`pytz.timezone('US/Pacific')`), normalized to UTC for storage and delta checks.
  - Day Shift: `06:00` to `18:00` Pacific. Target reminder: `17:00` Pacific (or immediately if plugged in $\ge$ 17:00), followed by 15-minute nags.
  - Night Shift: `18:00` to `06:00` Pacific. Target reminder: `22:00` Pacific (or immediately if plugged in $\ge$ 22:00 or 00:00–06:00), followed by 15-minute nags.
- **Discord Permissions & API**:
  - Requires Gateway Intent: `message_content = True`.
  - Notifications are dispatched as direct messages (`user.send()`) to `YOUR_USER_ID`. If the target user blocks DMs from server members, notifications will fail silently in Discord API catch blocks.
  - DM Cleanup: The bot tracks `state.last_reminder_id` and deletes the previous reminder DM before sending a new one to avoid spam.
  - Slash Commands: Synchronized on startup via `bot.tree.sync()`. Commands: `/plugged`, `/unplugged`, `/mute`, `/unmute`, `/clearchathistory`.
- **Deployment & Hosting (Proxmox LXC Container)**:
  - **Hosting Environment**: Production runs inside a container on Proxmox (target: `kali@10.0.0.225`, remote dir: `~/discord-car-charger-bot`).
  - **Pushing Changes**: Local `.\deploy.ps1` wraps and calls `F:\Games\Python\Coinbase\Grid bot\CentralDeployTools\deploy.ps1` to sync files and venv dependencies to the container.
  - **Restart Requirement**: After deploying changes, agents must **manually restart the service or the Proxmox container** for the new code to take effect (service executes via `@reboot` cron).
- **Environment Configuration**:
  - `.env` must define `DISCORD_TOKEN` and `YOUR_USER_ID`.
  - Optional overrides: `DASHBOARD_PORT` (default: `5000`), `REMINDER_HOUR` (default: `17`), `REMINDER_MINUTE` (default: `0`).
